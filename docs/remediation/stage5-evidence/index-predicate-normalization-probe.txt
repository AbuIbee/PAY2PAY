=== Conclusion ===

Two, and only two, rendering differences observed between drizzle's own predicate SQL and
PostgreSQL's pg_get_expr() rendering of the same stored predicate:
  1. Table-qualification + quoting: `"table"."column"` (drizzle) vs. `column` (PostgreSQL).
  2. An explicit `::enum_type_name` cast PostgreSQL adds to every literal compared against a
     custom enum column (drizzle never emits this cast). No `::text` cast was observed for any
     predicate in this schema — every literal comparison here is against a custom enum column,
     never a plain text column.
Both differences are stripped by normalizePredicateSql's two explicit, narrow regex rules
(quoting/qualification, and `::identifier` casts), verified against all 5 distinct partial-index
predicates this schema defines. No other normalization was found necessary or applied.
