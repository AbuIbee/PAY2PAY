## Program Gates

- Execute exactly one PRSprint at a time.
- Do not auto-start the next PRSprint.
- Product Sprint 19 is separate from PRSprint 19 and remains blocked until explicitly released by the Product Owner.
- Any new CRITICAL security, authorization, data-loss, or financial-integrity defect blocks progression.
- External provider dependencies must be marked `EXTERNAL BLOCKER` and feature-gated.
- Sandbox/mock functionality must never be represented as live production functionality.
- Only PRSprint 34 may issue the final controlled-launch production-readiness recommendation.

## Production-Readiness Chain

`UI -> API -> Authorization -> RLS -> Database -> Provider -> Webhook -> Audit -> Monitoring -> Recovery`

Green CI, attractive UI, committed migrations, sandbox payments, mock email/SMS, or placeholder card screens alone do not constitute production readiness.
